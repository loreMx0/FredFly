# FredFly
Fred and Steven the fly now joins hornet on her adventure 
If you see pink square move the fred and steven to the plugins folder or give your own path in config file

change fred and steven in the config file,change their size,speed and trail from the config file.
You can also create your own companion and replace it with fred or steven just make sure dimensions and name are exactly the same
